Apple's label concerns retained off-device data, including partners and optional flows. ## Linking and tracking decision

Account email, UUID, cloud content/history and associated purchases are linked in this implementation. No Sync account/routine/music data is passed into the ads integration. GMA's manifest flags and provider defaults still need assessment if that SDK executes; Store5's reachable consent request and the intended enabled-mode UMP behavior must be considered independently; the future disabled-mode guard does not settle every provider flow. An ATT prompt is absent. **Do not finalize either a blanket “tracking: yes” or “tracking: no” from manifests alone.** Validate the submitted configuration and partner behavior against [Apple's tracking rules](https://developer.apple.com/app-store/user-privacy-and-data-use/).

Historical Store4 Browser audio lets users navigate arbitrary HTTP/HTTPS sites without a separate app browsing/search-history log; selected media URLs can enter cloud metadata. The current candidate does not load that embedded browser/scanner or allow new URL acquisition in production/preview. Its four library links open externally, Files import remains, and previous saved URLs/metadata are preserved. Assess destination/provider traffic and existing URL playback separately; the new guard is not a blanket zero-collection or licensing claim. Apply Apple's open-web exception only to the actual selected binary's flows.
