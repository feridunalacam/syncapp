# Accounts and Sync Pro

## Architecture and plan

The hosted backend is the `syncapp` Supabase project (`iyipvwlhiwfaeyfoyakr`) in Frankfurt (`eu-central-1`), in the selected `Project 1` organization. This is not a local database. Migration SQL and function sources are versioned in this repository.

Free includes all existing local routines, timer, music controls, activity and guest mode. Accounts use email/password with confirmation, recovery, signout and deletion. Optional Apple/Google sign-in is behind explicit configuration flags. Spotify sign-in remains separate from the Sync account.

Sync Pro adds private cloud backup and cross-device synchronization of routines, recent activity history (normally the latest 100 saved sessions), bio, social links and locally saved posts. Merged guest imports can contain more activity records; the backup size limit still applies. Imported audio and profile photos remain device-local; routines retain their track metadata so files can be reselected on other devices. Pulling metadata back onto the original device preserves its matching local audio references. No public social network, advertising delivery or server-side music streaming is introduced.

Monthly and annual products map to a single RevenueCat entitlement named `sync_pro` (the internal database access key remains `pro`). The owner selected US$2.99/month and US$18/year, with no trial in the first release. Both prices are saved in App Store Connect, but no product or price has been published. The existing RevenueCat Test Store onboarding catalog is not a live App Store/Google Play product catalog. Store regional prices must be configured and approved in the merchant's console; the paywall always uses actual localized prices from the store, never these draft amounts.

## Data behavior

All personal device keys and music credentials are scoped to an immutable account ID. Signing out returns to a separate guest space. Account switches remount data/workout providers so the old state is not shown to the next user. Deleting an account requires a sign-in in the last 15 minutes, confirmation, server deletion, then a closed/drained local scope. Account deletion does not cancel an Apple/Google subscription; the UI offers its store management link before deletion. Purchase restoration is intended to transfer the paid entitlement to the new signed-in account, not to transfer the former account's private routines, profile or backups. The account data isolation rules remain unchanged.

Existing guest records are imported explicitly from Profile once per device installation. Existing account records win on ID collisions, and source guest records are removed only after a durable account copy and ownership marker exist. Music credentials are never imported or backed up; reconnect Spotify in the signed-in account.

Offline writes remain in account-scoped storage. Sync uploads use a persisted dirty counter and server revision. If another device changed the cloud backup while this device has edits, the UI asks which version to keep. A recovery snapshot is kept before cloud replacement. Synchronization pauses during an active workout. Media files, credentials, tokens and passwords are excluded from backups. Background sync retries on foreground and at one-minute intervals while Pro is active.
